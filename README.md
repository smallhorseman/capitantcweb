# Captain Tracy Charter Fishing Website

A modern, family-focused charter fishing website built with Next.js, showcasing Captain Tracy's 50+ years of Gulf Coast fishing expertise.

## 🎣 About

This website serves as a digital home for Captain Tracy's charter fishing business, emphasizing family bonding through fishing experiences. Currently featuring a "coming soon" charter booking funnel while Captain Tracy works toward his charter license, the site provides valuable fishing content and builds an audience for the future charter business.

## ✨ Features

- **Coming Soon Charter Funnel** - Email capture for pre-launch marketing
- **Fishing Reports** - Regular updates on Gulf Coast conditions and catches
- **Educational Blog** - Family-focused fishing content and tips
- **Video Library** - Tutorial videos and fishing guides
- **Fishing Tips** - Categorized advice for all skill levels
- **SEO Optimized** - Built for organic search visibility
- **Mobile Responsive** - Optimized for all devices
- **Family-Focused Design** - Emphasizes togetherness and memories

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17 or later
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd capitantracywebsite
```

2. Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the website.
